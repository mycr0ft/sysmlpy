# Plan: resolution truth from loaded library models (issue #34)

Downstream ask (CARTA, `repro_08`/analyze noise + the standing
advisory-noise debt): `LibrarySymbolIndex` is a *scraped name index*, so
the analyzer's library fallback answers "does the name exist somewhere in
the standard model?" without any of the semantics the real model carries.
Three false-positive classes ride on that:

| class | shape | why the index can't answer |
|---|---|---|
| re-export facades | `package ISQ {...}` re-exporting `ISQBase::*` | the index has `ISQ` members from the facade file *and* bare names; a reference through the facade resolves in the real model, not in a name list |
| star imports | `import SI::*;` then bare `kg`/unit expressions | "top-level package exists" is not in the index either way |
| doc-comment words | regex-scraped `.sysml` names carry doc text (`components`) | partially mitigated in #20 by loading .kerml; .sysml still scraped |

## Current state (0.101.0, probed)

- `LibrarySymbolIndex` (semantic.py:88): `get_symbols()` builds qualified
  names (`.kerml` parsed via kerml visitor dict; `.sysml` via the
  line-regex walk), cached in class attributes;
  `get_simple_names()` = last segment.
- Resolver fallbacks: `_is_implicit_library_reference` (semantic.py
  ~3195) and the duplicated block at ~3278 — both try
  `SymbolTable.lookup` → context resolution → **name-index membership**
  → `_KNOWN_LIBRARY_SIMPLE_NAMES`.
- Gate baseline (v0.100.1/0.101.0): 0 parse failures, **7888→7890
  errors**, 940 warnings (NAMING_CONVENTION 350 incl. the 9 library
  keyword declarations emitted since #25).

## Design: resolve on demand through loaded library models

Load the library *per failing resolution need*, not upfront:

1. **Fingerprint** (existing): `get_symbols()` already walks every
   library file; extend the walk to record `qualified_pkg_prefix →
   filepath` so any namespace need maps to its defining file(s).
   Implemented as a shared per-line harvester (`_leaves_on_line`, used by
   both the index walk and a **lexical** fallback walk) so the fingerprint
   costs 0.3 s instead of the index's .kerml parse — that is what keeps a
   cold resolver need cheap (LSP diagnostics). A cold `analyze` on a
   facade model went 56 s → 4 s.
2. **On-demand load**: `LibrarySymbolIndex.model_for_qn(qn, roots)`:
   - .sysml file → `sysmlpy.loads(text)` through the public pipeline
     (DFA-cached — gate runs warm) and cache per (file fingerprint);
   - .kerml file → still index-only this phase (KerML semantic loading
     rides #35/#34 follow-up; the false-positive classes above are all
     .sysml).
3. **Resolve against the loaded model**: put the loaded model through a
   fresh `SymbolTable` (the same machinery user models get) and check the
   reference in the namespace the index says defines it — facades resolve
   because the facade file real-parses, star-import visibility is the
   analyzer's own public/private rule, unit expressions resolve to the
   SI members the model really contains.
4. **Order**: `lookup → context → loaded-library model (NEW) →
   scraped-index simple name → known-names constant`. The scraped index
   stays as the last fallback (it catches .kerml-only names).
5. **Honesty rule** (standing): the next gate run reports the per-code
   delta with the constructs that caused it — errors legitimately drop
   (false positives resolve) or rise (previously masked members now
   analyzed); nothing is suppressed to fix counts.

## Phases

| step | what | size | unlocks |

| 4 | gate + full suite deltas reported; release 0.102.0 | 1 h | — |
| 5 | **model-resolved import visibility** — `library_namespace_table` wired into `_resolve_namespace_import`, built SHALLOW (direct members + short names); a deep build that resolved the library's own imports walked the whole closure (248 s cold). Gate: errors 3369 → 1183, warnings 2961 → 1706, every other code unchanged. | 6 h — DONE (0.102.5) | true member visibility for star imports |
| 6 (follow-up) | persist built namespace tables keyed by file fingerprint (dfa_cache-style): now a pure cost optimisation (+10 s on a cold analyze of a library-importing model), not a prerequisite for step 5 | 8 h | colder starts stop paying the table builds |
| 7 | **.kerml semantic model-loading** — a symbol table built straight from the KerML visitor dict (`_kerml_table_for_file`), plus lexical `.kerml` leaf fingerprinting so the path works in a cold process; `library_namespace_table` and `exists_in_loaded_model` both answer for KerML sources | 5 h — DONE (0.102.6) | full-library truth (VectorFunctions, VectorValues, kernel namespaces) |

Non-goals: changing the DEFAULT advisory strictness (the gate must stay
advisory by default); touching `reconcile`/identity layers.

Residual after step 5: a FACADE's re-exported members
(`ISQ::LengthValue` → `ISQBase`) are not in the shallow table, so the
import-*suggestion* warning for them survives on models that import the
facade. References still resolve through `exists_in_loaded_model`. Closing
this needs either the deep table (248 s cold) or lazily resolving a
table's own imports at lookup time.
